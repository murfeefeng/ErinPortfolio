平台服務約定條款及細則

一、服務範圍

  1. 本公司透過網路平台提供遊戲點數、虛擬貨幣、會員儲值碼等電子序號商品（以下簡稱「數位商品」）之銷售服務。
  2. 所提供之數位商品來源合法，並與原廠／授權代理商取得合作或進貨來源保證。

二、使用者資格與帳號管理

  1. 使用者須年滿18歲或已獲得法定代理人同意，方得使用本平台進行交易。
  2. 使用者註冊帳號時，應提供正確且完整之個人資訊，若資料有異動，應即時更新。
  3. 使用者應妥善保管帳號與密碼，如因保管不善導致帳號被盜用，概由使用者自行負責。
  4. 若本公司發現帳號有異常使用、違反本條款或疑涉非法行為者，得立即暫停或終止其使用權限。

三、交易條款

  1. 數位商品為一次性消費性虛擬商品，售出後即視為交付完成。
  2. 所有價格均以新台幣計算，若有錯誤標示，將依實際公告價格為準。
  3. 使用者完成付款後，系統將自動或人工方式發送數位商品序號至使用者提供之電子信箱或平台帳號中。
  4. 請使用者於收到序號後妥善保管，若因個人疏失導致序號外洩或遭第三人使用，恕不補發或退換。

四、退換貨政策

  1. 依《通訊交易解除權合理例外情事適用準則》，本平台販售之數位商品不適用七日鑑賞期規定。
  2. 若因本公司疏失導致發送錯誤序號、無效碼或重複碼，經確認後將予以更換或退費處理。
  3. 使用者提出退款申請時，需於購買後48小時內聯繫客服，並提供相關證明資料。
  4. 凡數位商品一經兌換、儲值或啟用，恕不接受任何形式之退費申請。

五、使用限制與責任

  1. 禁止使用本平台從事任何違反法律、侵害第三人權益或破壞交易秩序之行為。
  2. 使用者不得利用系統漏洞、外掛程式或其他非法手段進行交易。
  3. 若違反前述規定，導致本公司或其他使用者損失，使用者應負全部民事與刑事責任。

六、智慧財產權聲明

  2. 未經授權不得重製、修改、散布或用於商業用途。

七、免責聲明

  2. 因天災、戰爭、黑客攻擊、系統維護等不可抗力因素，導致服務中斷或資料遺失時，本公司不負賠償責任。

  2. 使用者若於條款修訂後繼續使用本服務，視為同意新條款之內容。
